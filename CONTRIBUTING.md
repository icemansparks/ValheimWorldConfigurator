# Contributing

Translations, corrections to modifier values, and fixes are all welcome.

## Before you open a pull request

Modifier names and values should be verified against a real dedicated server
rather than copied from a wiki. The manual shipped with the server is
incomplete in places and some wiki pages are years out of date. If you are
correcting a value, say in the pull request how you checked it.

The names and values the server accepts are listed in
[`tools/server-vocabulary.json`](tools/server-vocabulary.json), taken from the
manual and the server's argument parser for the build named there. After any
change to modifiers, presets or checkboxes, run:

```bash
node tools/check-vocabulary.js
```

It fails when the tool emits or cannot import a name or value that is not in
that list. For a pull request that updates the tool to a new server build,
refresh the list from that build, then start a command generated by the tool
itself (not typed by hand) with every modifier set to a non-default value, and
confirm the world file reads back the expected
`combat_x:deathpenalty_x:resources_x:raids_x:portals_x` string. The server
does not stop on an unknown name or value; it logs `Could not parse ...` and
starts the world without it.

For translations, see [`lang/README.md`](lang/README.md) and run:

```bash
node lang/check-languages.js
```
